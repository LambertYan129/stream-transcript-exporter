# Microsoft Stream 转录导出

在 Microsoft Stream 视频页点一下 **导出转录 TXT**，把当前视频已有的转录保存为带时间戳的文本。适合把课程或会议转录整理成笔记，之后按时间回到视频对应位置。

**当前版本 v1.0.0** · [获取油猴脚本](./stream-transcript.user.js) · [版本说明](./RELEASE.md)

## 安装

1. 在观看视频的浏览器中安装 [Tampermonkey（篡改猴）](https://www.tampermonkey.net/)。
2. 在本仓库打开 [stream-transcript.user.js](./stream-transcript.user.js)，点击文件右上方的 **Raw**。如果油猴弹出安装页，点击 **安装**。
3. 如果浏览器直接显示源码，返回 GitHub 文件页，点击 **Download raw file** 保存脚本。打开油猴的 **管理面板 → 实用工具 → 从文件导入**，选择刚下载的 `.user.js` 并确认。
4. 在油猴的 **已安装脚本** 中确认「Microsoft Stream 转录导出」已启用，然后刷新视频页。升级已有脚本时，同样导入新版并确认更新。

## 导出一段视频的转录

1. 打开有权查看的 Stream 或 SharePoint 视频，展开右侧 **转录** 面板，等到时间和字幕正文出现。
2. 暂停播放，清空转录搜索框。点**网页右下角紫色的「导出转录 TXT」**。
3. 按钮旁会显示读取进度。提取期间保持页面打开，让脚本自行滚动字幕列表。
4. 完成后，在浏览器的下载记录中打开以视频标题命名的 `.txt`。每条字幕占一行，同一秒出现的不同句子会分别保留。

例如，视频中连续两句都从第 5 秒开始时，文件内容如下。

```text
[0:00] 今天我们来读一段程序。
[0:05] 先看第一行。
[0:05] 这里定义了一个变量。
```

## 怎样判断是否读全

| 页面提供的信息 | 导出时的检查 |
| --- | --- |
| 有条目序号和总数 | 进度显示为「已读取 240 / 1011」这样的计数。收齐全部序号后下载。 |
| 没有总数 | 根据相邻两屏重叠的字幕拼接列表。两次从头到尾的扫描逐行一致后下载，完成提示注明「两遍一致，页面未提供总数」。 |

第二种方式只能确认两次读取结果一致。脚本读取页面上已有的字幕，一次处理一个视频，不会识别音频或生成缺失的字幕。文本在浏览器内生成。

## 常见情况

| 遇到的问题 | 处理方式 |
| --- | --- |
| 只有转录面板里灰色的「下载」 | 脚本的按钮固定在网页右下角。检查油猴中脚本是否启用、浏览器是否允许油猴在当前网站运行，然后刷新视频页。 |
| 提示「未识别到字幕行」 | 展开转录面板，确认能看到带时间的正文。如果视频嵌在课程网页中，打开视频自己的 Stream 页面，再试一次。 |
| 提示「滚动时字幕未连续衔接」或只收集到部分条目 | 暂停视频，清空字幕搜索，重新打开转录面板再导出。 |
| 文本中出现 `[0:05] 0 分钟 5 秒` | 在油猴中确认已启用 **v1.0.0**，刷新视频页并重新导出。脚本会清理与方括号时间相同的中文时间前缀。 |
